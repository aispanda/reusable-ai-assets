# {{PROJECT_NAME}} — Engineering Principles

- Optimize for measurable user outcomes, modularity, and reversible choices.
- Let AI reduce implementation effort; do not let generated code bypass review, tests, security, or ownership.
- Prefer open interfaces and swappable providers where change is plausible.
- Keep authoritative data ownership explicit.
- Build the smallest end-to-end slice that proves the architecture.
- Automate repeatable validation; keep human approval for consequential choices.
