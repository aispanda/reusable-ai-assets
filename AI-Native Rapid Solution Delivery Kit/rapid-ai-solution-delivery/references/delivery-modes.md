# Delivery modes

Start Lite. Move up only when a trigger is present.

| Mode | Use when | Added control |
|---|---|---|
| Lite | Solo/small-team POC, reversible decisions, fictional or low-risk data | Seven concise planning artifacts and build brief |
| Standard | Multiple agents/teams, meaningful integrations, several technology layers, MVP/pilot | Separate principles, research, architecture, data, seeds and technology-options artifacts |
| Controlled | Customer/regulated/sensitive data, material spending, production change, formal approvals | Risk/security and compliance-evidence registers |

Mode does not measure project importance. It determines how much evidence and separation are needed to make changes safely.

Activate optional folders by trigger, independently of mode:

- **Research vault:** external/current evidence materially affects scope or a decision.
- **AI exchange:** more than one AI tool or agent will produce, review, or implement bounded work.

Downgrade when controls no longer add value; archive superseded modules rather than copying their facts into Lite documents.
