# Dimensions — Information to Vision

Owner-grounded sense-making dimensions for Insight Forge. Source corpus: owner writings under Knowledge Base/Writings (Consulting hierarchy, Vision Share). Treat as **operating dimensions**, not a climb-only pyramid.

## Stack

| Dimension | Job | Linearity | Typical mode |
|---|---|---|---|
| Information | Data / facts | Linear | Analytical |
| Knowledge | Arrangement of facts with structure and utility; time-bounded | Linear | Analytical |
| Insight | Principles / patterns; **deconstruct and reconstruct**; bridge | Bridge | Analytic → synthetic |
| Imagination | Story, hypothesis, TO-BE narrative not yet present to the senses | Non-linear | Synthetic |
| Wisdom | Inclusive container of interconnected insights; open to opposing views | Non-linear | Synthetic |
| Vision | Jump to a luminous, audacious, inclusive, yet pragmatic future picture—often in Flow | Non-linear | Synthetic |

## Insight as Fire (core algorithm)

1. Break AS-IS knowledge into MECE / first-principle atoms.
2. Hold tensions and cross-domain joins.
3. Reconstruct TO-BE knowledge, frameworks, or designs.
4. If attention fails, allow peripheral / subconscious candidates—then verify.

## Vision checks (depth / breadth / height)

| Axis | Question |
|---|---|
| Depth | Realistic, practical, plan-detailed enough? |
| Breadth | Scope inclusive enough (who is left out)? |
| Height | How far is TO-BE from AS-IS (radical vs incremental)? |

## Human gates

- Machines may propose insight/imagination/vision **candidates**.
- Humans own: value judgment, identification, delusion check, and public commitment.
- Watch for **narcissist vision**: sold for admiration, distorted for applause, then drained of capacity.

## Evidence boundary

This file does not own research claim labels. Use the evidence-status and optional claim-role taxonomy in [`research-loop.md`](research-loop.md). Insight, imagination, and vision candidates do not become observed facts merely because they are compelling.
