# Reusable AI Assets

Portable tools, templates, skills and delivery systems for AI-enabled projects. Each asset has a concise record describing when to use it, what to transfer, how to verify it and where its boundaries lie.

Start with the [asset inventory](REUSABLE_ASSET_INVENTORY.md). Load only the selected asset's `ASSET.md` and linked components to minimize context and token use.

## Publication standard

- Fictional or generic examples only.
- No credentials, customer data, personal machine paths or generated dependencies.
- Project-specific settings belong in external configuration or profiles.
- Status reflects observed verification; draft or pilot assets are not presented as production-ready.

Every consumer should review security, licensing, dependencies and environment-specific settings before use.
